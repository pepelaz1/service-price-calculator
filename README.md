# Мастер рядом — демонстрационный калькулятор услуг

Небольшой full-stack проект для портфолио: React + TypeScript, Node.js API и SQLite. Посетитель выбирает город, услугу, количество устройств и срочность; сервер возвращает подробную смету. Это учебный пример, цены и услуги вымышлены, реальные заказы сайт не принимает.

## Что внутри

- React-интерфейс с адаптивной версткой и состояниями загрузки/ошибки.
- `GET /api/catalog` получает тарифы и города из SQLite.
- `POST /api/quote` проверяет входные данные и считает стоимость на сервере.
- SQLite открывается только для чтения; поэтому демо работает в бессерверной функции без платной базы данных и без риска потерять изменения при холодном запуске.
- Одна и та же логика API используется локальным HTTP-сервером и Yandex Cloud Function.

Формула: `работы = round(базовая цена × количество × коэффициент города / 10000)`; `срочность = round(работы × 20%)`; `итого = работы + выезд + срочность`.

## Запуск локально

Нужны Node.js **22.13+** и npm. В более ранних версиях Node 22 модуль `node:sqlite` ещё требует флаг `--experimental-sqlite`; скрипты проекта передают его явно.

```powershell
npm ci
npm run db:seed
npm test
```

В двух терминалах:

```powershell
npm run api
```

```powershell
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`). API слушает `127.0.0.1:8787`, а Vite проксирует `/api`.

## Размещение в Yandex Cloud

Этот раздел — подготовка к будущему деплою; облачные ресурсы пока не созданы. Для облачной функции выберите Node.js 22.15+.

1. `npm run build` — готовый фронтенд в `dist/`.
2. `python scripts/package_function.py` — ZIP с кодом API и демонстрационной SQLite-базой в `dist/function.zip`.
3. Загрузите `dist/index.html` и папку `dist/assets` в Object Storage.
4. Создайте Cloud Function с ZIP из шага 2, средой `nodejs22` и точкой входа `index.handler`. Функцию можно сделать публичной для вызова через шлюз либо выдать шлюзу сервисный аккаунт с ролью `functions.functionInvoker`.
5. Создайте API Gateway по шаблону `deploy/gateway.yaml`, заменив `BUCKET_NAME` и `FUNCTION_ID`. Он отдаёт фронтенд и API через один адрес, поэтому CORS не нужен.
6. Проверьте `/api/health`, `/api/catalog`, расчёт через страницу и загрузку CSS/JS. Затем проверьте ссылку из российских сетей без VPN.

Все маршруты в шаблоне указаны явно. Если захотите в будущем добавить страницы или файлы, обновите спецификацию шлюза. Бакет в шаблоне открыт для чтения; для закрытого бакета добавьте сервисный аккаунт в интеграции Object Storage.

Не храните секреты в репозитории. В текущем демо секретов и персональных данных нет. Бесплатные квоты Yandex Cloud не являются жёстким лимитом расходов: после их исчерпания возможна тарификация. Для платежного аккаунта без карты Yandex Cloud требует первоначальное пополнение баланса.
